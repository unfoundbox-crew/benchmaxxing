benchmaxxing.lol

SOTA charts for non-SOTA models. A tiny benchmark-chart renderer for launch posts, papers, dashboards, and one very specific kind of AI Twitter brain damage.
Important: the included scores are synthetic satire, not claims about real models. The renderer keeps numeric bar geometry faithful to the data even when the API names are unserious.

Install

npm i @benchmaxxing/charts

Node or browser. No runtime dependencies. Generates plain SVG strings, so it also works in build pipelines.

API

import { benchmaxx } from "@benchmaxxing/charts"; const svg = benchmaxx({ models, benchmarks, highlight: "ours", visualBias: "startup" });

CLI

benchmaxxing \\ --preset meridian-dawn \\ --out launch.svg

Or provide your own JSON config with --input.

Chart crimes not included

  • No fabricated geometry.
  • No hidden axis manipulation.
  • No fake real-world benchmark claims.
  • Just excellent-looking bars and questionable benchmark names.
